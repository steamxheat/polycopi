## 1. Цель и правила игры

**Цель:** свой прибыльный бот для рынков Polymarket «BTC/ETH Up or Down» (окна 5 и 15 минут).
Не копировать чужих — учиться на ошибках и проверять всё цифрами.

**Девиз владельца:** «мы никогда не закроем эту тему, мы сделаем результат». Если идея не работает — следующая.

**Деньги:** бюджет на реальную торговлю **$150**. Всё сначала доказывается на **виртуальных деньгах**.

**Путь к реальным деньгам:**
1. подбор лучшего варианта (1–2 дня);
2. **экзамен — 7 дней на виртуальных деньгах** (плюс за неделю, ни одного дня хуже −$15, сотни сделок);
3. реальные **$20–50**, стопы: −$15 за день, −$40 всего;
4. если неделя в плюсе — до **$150**.

Ориентир по датам: подбор 28–29.10 → экзамен 30.10–05.11 → реальные малые суммы ~06.11 → $150 ~13.11.

**Честные оценки (на 28.10 вечер):**
- шанс получить стратегию, готовую к реальным деньгам, к ~06.11: **~50%**;
- удвоить $150 за месяц: **~3–5%**; за 3 месяца ~10–15%; за 6 месяцев ~15–20%;
- реалистичный заработок рабочей стратегии на $150: **~$1–5 в день**.

## 2. Как мы работаем (важно для нового чата)

- Владелец (Илья) **сам вставляет команды** в терминал своего Mac и присылает вывод. Ассистент даёт команды и объясняет простыми словами, по-русски.
- **Все команды — в «правом окне» терминала Mac** (строка `ilyaosipov@MacBook-Pro-4 ~ %`). Команды сами заходят на серверы через `ssh`.
- **Длинные команды обрезаются при вставке** (zsh `quote>` / `parse error`). Решение: держать команды короткими, сложное — выносить в скрипты в репозитории (`scripts/*.sh`) и запускать `bash scripts/...`.
- Код правит ассистент в репозитории `steamxheat/polycopi` (GitHub), прогоняет тесты, пушит в `main`. На сервере — `git pull`.
- **Безопасность:** паролей, токенов, приватных ключей **не запрашивать и не выводить**. Токен приложения копировать только локально (`pbcopy`), в чат не присылать.
- **Географические ограничения Polymarket:** не помогать обходить. Торговать реальными деньгами — только оттуда, где человек реально находится и где это разрешено (Нидерланды/Ирландия — API разрешён; Великобритания, США, Россия и др. — нет). Сервер в Лондоне невозможен (UK заблокирована).
- Не удалять `data/` и папки с данными ботов. Не запускать второй экземпляр копи-бота.

## 4. Рынок — что мы узнали (ключевые факты)

- **Правило расчёта окна:** итог = **средняя цена Chainlink за последние 60 с окна** против средней за минуту перед стартом («t60»). Подтверждено на 97–99% реальных итогов.
- **Рынок в среднем откалиброван:** «модель против рынка» в обычный момент — рынок чаще прав.
- **Прибыльные кошельки (goodfallen, almach, b27b)** — в основном мейкеры; у некоторых плюс на **фаворитах**.
- **Чистый арбитраж Up+Down < $1** бывает, но держится 0.00 с — **забрать нельзя** (24 случая, подтверждено $0).
- **Скорость источников цены (1423 рывка, из Нидерландов):** быстрее всех **фьючерсы Bybit (bybit_perp, отставание ~10 мс)** и **OKX (okx_perp, ~22 мс)**, затем okx_spot, coinbase. **Binance через зеркало `data-stream.binance.vision` опаздывает (медиана ~180–700 мс, хвосты до секунд)**, Polymarket RTDS ~2 с. Фьючерсы Binance (`fstream`) из NL **недоступны**.
- Профи стоят в Дублине/Амстердаме (как мы), их преимущество — быстрые потоки цен (Азия, платный Chainlink Data Streams), C++/Rust и капитал. Соревноваться в чистой скорости бессмысленно; ищем ниши.

## 9. Карта кода (`polycopi`)

| Файл | Что это |
|---|---|
| `fvsim.py` | тейкер-симулятор (варианты в одном процессе). Фильтры варианта: `min_edge`, `max_edge`, `rule` (spot/t60/wt), `min_tau`/`max_tau`, `min_p`/`max_p`, `min_ask`/`max_ask`, `assets`, `windows`, `move_bps`/`move_s`/`ask_stale_s`/`ask_not_up` (запаздывание). Пишет `snapshots.csv` (секундные снимки), `trades.csv`, `outcomes.csv` |
| `fvmodel.py` | модель вероятности по правилам spot/t60/wt, посекундный сэмплер цен |
| `mmsim.py` | мейкер-симулятор; `multi` — много вариантов в одном процессе (`mm_grid.json`); `grid` — таблица сетки; `learn` — разбор «фото рынка» одиноких ног; источники цен, в т.ч. `bybit_perp`/`okx_perp` |
| `backtest.py` | массовая проверка ~100 стратегий тейкера на `snapshots.csv` с защитой от подгонки (две половины, z ≥ 2) |
| `feedlat.py` | гонка 10 источников цены (кто первым приносит рывок) |
| `arbwatch.py` | наблюдатель чистого арбитража Up+Down < $1 |
| `simbot.py` | копи-бот (повторяет сделки сильных трейдеров) |
| `liveprobe.py` | **калибровка настоящими заявками** ($1–3 каждая). `check` — разбор интерфейса библиотеки, `dry` — без ключей и отправки, `live` — с лимитами по числу заявок/сумме/цене и файлом STOP. Ключ только в `~/.polymarket.env`, в журнал не попадает |
| `scripts/wherehost.py` | где стоит сервер биржи: HTTP-замер из городов через Globalping, с пометкой, откуда API-торговля разрешена |
| `scripts/extremes.py` | крайние сделки варианта + разбор прибыли по цене покупки |
